🤝 Contribuir a IncluClass

¡Gracias por tu interés en contribuir a IncluClass!
Queremos construir una comunidad inclusiva y colaborativa.
Por favor, sigue estas pautas para mantener un entorno de trabajo organizado y respetuoso.

🛠️ Cómo contribuir

Fork este repositorio.
Crea una nueva rama para tu cambio:
git checkout -b nombre-de-tu-rama
Realiza tus cambios de manera limpia y concisa.
Asegúrate de seguir las reglas de estilo del proyecto ejecutando:
npm run lint
Haz commit de tus cambios:
git commit -m "Descripción clara de lo que hiciste"
Haz push a tu rama:
git push origin nombre-de-tu-rama
Abre un Pull Request en el repositorio original.
✍️ Buenas prácticas

Commits claros: Usa mensajes de commit descriptivos.
Código limpio: Sigue las reglas de ESLint y mantén un estilo consistente.
Funciones pequeñas: Trata de que cada Pull Request sea pequeño y enfocado en un solo cambio o feature.
Documenta tus cambios si es necesario (actualiza README o comentarios en el código).
Pruebas: Si tu cambio afecta a la base de datos o funcionalidades clave, incluye pruebas o instrucciones para probarlo.
💬 Comunicaciones

Usa los Issues para reportar errores o proponer nuevas ideas.
Sé respetuoso y considerado en todas las interacciones.
